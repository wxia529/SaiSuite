# v1.3.1 科研工具范围调整

版本：1.3.1+8，2026-10-04，当前共 60 项工具。

按用户要求删除以下四项：

| 工具 ID | 已删除功能 |
|---|---|
| N06 | 循环数据分析 |
| N07 | 锂金属测试分析（Li‖Cu 效率、Li‖Li 极化） |
| EC21 | 电流积分与容量 |
| N02 | 梯度配方 |

删除包括目录入口、搜索、首页推荐、专用页面、路由和对应计算代码。升级时只清理这些 ID 在收藏与最近使用中的快捷入口，保留其他工具的顺序、主题、计算器历史、番茄钟状态与标尺校准。用户已导出的 CSV、PNG 或其他文件不会因此被删除。

继续保留电解液配方及实际称量反算、装电池备料、测试参数和电导率换算，以及电极面积、归一化、理论比容量、N/P、浆料配方、电解液用量、溶剂配比、参比电位换算和 iR 校正。基础科研、PDF、日常计算、文本、日期、创作和设备工具继续提供；保留工具原有的文件导入、主动导出能力。

此前四项功能可从 Git 历史及旧版本验收文档追溯。当前工程没有 Windows 平台，不因移除而建立 Windows 版或重新排期上述功能。

安装包继续同时提供 Universal 和三个独立架构包；升级需沿用原签名和适配设备的架构。
