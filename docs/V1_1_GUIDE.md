# v1.1.0 新增工具

更新日期：2026-10-04。原 46 项工具新增 17 个入口，共 63 项；C01 增加点按键盘，原颜色转换保留，A01 提供组合配色。

## 日常与设备

| 工具 | 操作与实际范围 |
|---|---|
| C01 点按科学计算器 | 光标/选区插入，数字、四则、括号、函数、AC、退格和等号。函数自动插入左括号，乘法需明确输入，% 为取余；结果位于键盘上方，可复制/导出。 |
| A01 配色助手 | HEX/RGB/HSL 输入，互补、类似、三色组合；单色或整组复制，显示基色与黑白对比度。组合建议不代表所有文字搭配均可读。 |
| A02 图片取色器 | 图片双指缩放/移动后点按读取原图像素；显示 HEX、RGBA 和坐标。20 MB / 1600 万像素，透明像素显示 Alpha，不与预览背景混色。 |
| A03 番茄钟 | 专注/短休息/长休息、轮数，开始/暂停/继续/跳过/重置，到时通知。修改时长后重置应用配置；每段结束后手动确认下一段。只保存当前状态与设置。 |
| A04 画板 | 点按/拖动、画笔粗细/颜色、橡皮、撤销/重做、确认清空，导出 900×900 PNG；不自动保存作品，未导出离开时提示。 |
| A05 指南针 | 磁北方位角、精度状态和校准提示；硬件缺失时不可用。不请求定位，不输出真北。 |
| A06 水平仪 | 双轴倾角、气泡，当前姿态归零、重置校准；读数与手机表面和传感器有关。 |
| A07 传感器读数 | 按设备实际硬件显示照度、气压、磁场、加速度、重力、角速度、旋转向量，标出单位和缺失状态；不保存采样历史。 |
| A08 屏幕标尺 | 用实体尺测量校准线，输入实际 mm 后应用校准；横向/竖向、毫米/厘米/英寸，双标记测距及有效范围。只保存校准设置。 |
| A09 图片工具 | 单图百分比裁剪、旋转、翻转、缩放、JPEG/PNG、文字水印；多图横向/竖向/网格拼图。输入信息、结果预览及另存新文件。 |
| A10 视频工具 | 文件信息与预览、时间段截取、静音、截帧、输出高度和目标码率、进度、取消，结果预览后另存。 |

番茄钟使用截止时间计算剩余时长，后台提醒使用非精确系统闹钟，可能延迟；通知也受省电、权限、强行停止或设备重启影响，不用于关键实验定时。传感器和屏幕标尺用于日常估测，实体手机需要现场校准。

图片单张上限 30 MB，最多 9 张；解码长边最多 4096 px，拼图各输入长边最多 1024 px，输出长宽均不超过 4096 px。裁剪基于 EXIF 方向处理后的图像。拼图为等比例居中的等大格子。JPEG 填充白底，质量滑块只影响 JPEG；PNG 无损，原文件元数据不保证完整保留。

视频单文件上限 500 MB；Media3 1.11.1 与设备编解码器输出 MP4/H.264/AAC。目标码率不是精确值，输出不保证小于原件。格式与编码支持取决于设备，失败显示错误；截帧时间受帧率影响。另存为用流式复制，不把整段视频载入 Dart 内存。

## 电解液与纽扣电池

| 工具 | 计算与输入口径 |
|---|---|
| N01 电解液配方 | 多盐、多添加剂、溶剂质量比；按溶剂质量/最终质量/最终体积求称量，或按实际称量反算。支持 mol/kg 溶剂、mol/L、wt% 有效盐及纯度修正。 |
| N02 梯度配方 | 第一种盐浓度×第一种添加剂最终 wt%，最多 36 组；每组目标量相同，其余组分不变。单个值可固定一个变量。 |
| N03 装电池备料 | 指定数量、每颗加液量和百分比/固定 µL 余量，计算电解液及耗材总数；不按电池型号推荐用量或装配方案。 |
| N04 测试参数换算 | I=jA、Q=qA、t=Q/I，面积换算电流/容量，参考容量用于 C-rate；时长不包括恒压和静置。 |
| N05 电解液电导率 | σ=K/R；几何口径 K=L/A。输入匹配测试结构的体相电阻、常数或厚度/面积，不用整电池总阻抗替代。 |
| N06 循环数据分析 | UTF-8 CSV/TSV/分号，列映射样品、循环、已配对充电/放电容量；CE、指定基准保持率、指定循环的平行样均值与样本标准差，曲线及 CSV/PNG 导出。 |
| N07 锂金属测试分析 | Li‖Cu 逐圈剥离/沉积容量 CE；Li‖Li 按样品、循环、步骤、时间与电压，排除起始区间后统计平均绝对电压。 |

mol/L 使用最终溶液体积，mol/kg 使用溶剂质量；体积目标或 mol/L 配方需要实测最终溶液密度，不能把加盐前溶剂体积当最终体积。添加剂 wt% 以最终电解液总质量为分母。盐摩尔质量须对应实际试剂形态，纯度表示有效盐质量比例，修正称量而不推断杂质成分。示例只演示计算，不是推荐配方；不判定溶解度或电化学适用性。反算未提供最终体积时不猜测 mol/L。

数据分析支持 2 MB、50000 行、20 个样品。单位为 mAh、V、s，需表头；输入容量已经由用户确认配对，不宣称自动解析所有仪器原始步骤文件。同一样品同一圈重复汇总行拒绝，保持率须有有效基准圈。CE 超过 100% 保留并提示；缺少对比圈者明确排除该圈统计，单样品不计算样本标准差。

Li‖Li 允许不同步骤时间重置，同一样品/循环/步骤内必须严格递增。平均绝对电压是采样点算术均值，不是时间加权平均或单电极过电位，不凭长循环时长判断短路。曲线支持缩放/平移；没有内部样品库、进阶拟合或仪器格式自动识别。

## 数据与验证

新科研工具不把输入、结果或导入数据写入偏好设置/实验数据库；只分析当前会话。用户主动选择保存位置导出，取消或失败不提示成功；未导出结果/画布/媒体离开时提示。原件只读，输出新文件。入口收藏和最近使用只保存工具 ID；计时状态、主题和标尺校准属于应用设置。

静态分析、逻辑/界面测试、Android 原生集成、签名与包体的实际证据见验收记录。集成素材来自 AndroidX Media3 测试资源，测试包后缀 `.dev`；正式包没有测试入口或网络请求。模拟器验证不等同于实体传感器精度或所有视频编码器兼容性。
