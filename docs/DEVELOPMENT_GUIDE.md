# 开发指南

本文件说明当前维护范围与约定；使用方式见 [使用指南](USER_GUIDE.md)，环境和命令见 [构建说明](BUILD.md)，逐版变化见 [发布记录](releases/README.md)。

## 产品范围

维护 Android 与 Windows 工具箱：PDF、图片／视频、日常计算、文字、配色、计时、设备和科研计算。科研面向配液、电解液和纽扣电池备料等明确输入条件的即时计算；此前未实现的电化学候选功能池已放弃，不再作为开发目标或保留排期。

不建设实验记录、配方历史、样品数据库、仪器控制或 CSV 曲线分析。既有输入和结果由用户主动导出，不能依赖内部缓存留存。PDF 保持文件与页面工具范围，不接回正文编辑原型。

界面使用中文、统一配色和间距，独立工作台各自处理输入、预览和导出；不强调工具数量，不出现“本地处理”“离线可用”等装饰文案。图片取景必须考虑横图和竖图，支持移动和缩放；手势不能被父页面滚动抢走。预览与最终导出共用几何和参数，错误出现后不能继续展示旧结果。

## 代码结构

| 位置 | 职责 |
|---|---|
| `lib/app/` | 导航、分类、搜索、收藏、设置和关于页面 |
| `lib/features/catalog.dart` | 入口、编号、字段与搜索别名；平台可用性由导航层筛选 |
| `lib/features/` | PDF、图片、图文、媒体、配色、画板、计时和传感器工作台 |
| `lib/core/` | 计算引擎、电解液模型、图像几何、文本处理、状态、更新与平台通道 |
| `android/app/src/main/kotlin/` | Android PDF、媒体、OCR、文件、硬件与通知实现 |
| `windows/runner/`、`windows/backend/` | Windows 平台通道、窗口与处理组件；OCR 使用系统接口 |
| `assets/branding/`、`assets/fonts/`、`assets/licenses/` | 统一图标、彩色 emoji 字体和许可证 |
| `test/`、`integration_test/`、`tools/tests/` | 计算／界面、设备／桌面和发布脚本验证 |

新增能力通过既有通道和处理服务接入。Windows 专属 Python／FFmpeg 不加入 Flutter 公共 assets，因此不会进入 Android APK。图标从 `tools/generate_app_icons.py` 统一生成，Windows 程序与安装器、Android 传统／自适应／主题图标保持一致。

## 数据与输出约定

- 原始输入只读，修改与转换输出新文件；取消、失败和缓存清理不能删除用户输入。
- 科研输入、配方和创作会话不新增自动保存，未导出离开时提供继续、导出或放弃选项。
- 只将主题、入口收藏／最近使用、普通计算器历史、更新设置、番茄钟状态和标尺校准写入既有偏好存储。
- 对非有限数值、空字段、无效单位、超限文件和缺少硬件明确报错；校验错误定位到具体输入。
- 科研模型说明公式、单位和适用条件，质量守恒、浓度口径和纯度边界需验证；定义见 [科研口径](SCIENCE.md)。
- 文件保存仅在实际写入成功后标记已导出；临时文件不作为用户成果目录。

## 测试与验收

默认设备为 `SaiSuite_API_36`，每次核对实际设备 ID 和 `ro.build.version.sdk=36`。端口可能变化；Android 16 测试不能代替最低系统、大图内存、实体传感器、相机、声音与通知验证。Windows 采用真实桌面测试，Windows 11 和特殊编码器按改动补充。

Flutter 测试、设备测试与平台构建顺序执行，避免同时修改生成的插件注册文件。正式构建保留默认依赖准备步骤，不在集成测试后直接用 `--no-pub`。

| 改动 | 应核对的行为 |
|---|---|
| 计算与文本 | 独立已知值、单位换算、守恒、边界、非法输入和 Unicode |
| 图片与画板 | 横／竖图、裁切坐标、手势、透明度、导出像素、原件保持和窄屏 |
| PDF | 页序、重复页、旋转、混合页面尺寸、密码、水印与独立解析／渲染 |
| 视频与音频 | 实际编解码、尺寸、时长、音轨、输入哈希和实际截帧 |
| OCR 与设备 | 平台真实调用、资源缺失、权限拒绝与不可用提示 |
| 更新与发布 | 平台／架构匹配、URL 校验、版本、签名、附件完整性与 SHA-256 |
| Windows 安装 | 完整包、快捷方式、运行保护、覆盖更新、卸载与用户文件保留 |

按改动选择已有测试，不为纯文案、图标等可逆小改动重复建立镜像测试。设备集成测试使用专用模拟器，测试运行器可能卸载调试应用。运行结束按需要恢复调试主程序。

验证日志、截图、临时输入和包检查报告写入 `.buildlog/`；测试包放入 `dist/development/` 的独立目录。发布说明写本版检查结果，不在主文档堆叠每轮日志和旧包体积；历史证据保留在 Git 历史及原测试产物中。

## 版本、提交与文档

版本源为 `pubspec.yaml`，显示版本为 `lib/core/updates.dart` 的 `appVersion`，两者保持一致。只有用户明确要求时升级；构建号严格增加，SDK 设置不随测试设备变更。

Git commit 标题和正文描述改动，不出现版本号或构建号，不改写此前提交。例如 `fix: unify app icons and refine image interactions`、`docs: consolidate project guides and release notes`。版本记录集中在 `docs/releases/`，标签仍遵循 `vX.Y.Z+BUILD`。

用户操作变更更新使用指南；架构与约束更新本文件；环境更新构建说明；发布流程更新发布说明；模型和许可分别更新科研口径、依赖文档。不再为单轮改动增加独立版本指南，流程见 [发布流程](RELEASING.md)。
