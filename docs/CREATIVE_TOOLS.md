# 创作、文字与日常工具扩展

用户选定的功能已增加为 22 个独立工作台。当前版本为 1.4.1+10；Android 共 82 项工具，Windows 共 79 项，传感器三项仍只在 Android 显示。未加入被删除的联网查询、AI 上色／人脸融合、清理器和实验记录功能。

## 功能与操作

| 工作台 | 实现 |
|---|---|
| 时间屏幕、手持弹幕 | 全屏时钟／滚动文字；字号、字体、文字／背景颜色、速度、横竖屏。Windows 支持无边框全屏并恢复窗口；Android 大屏的旋转行为仍受系统策略影响 |
| 秒表与分段 | 实际经过时间计时，暂停、分段、重置、TXT 导出；最多 200 段 |
| 记分牌 | 队伍名称、加减比分、撤销、确认重置、主动导出；比分 0—999 |
| 反应力测试 | 随机等待、抢跑拒绝、离开应用中断、最快／平均成绩；只保留当前页面最近 20 次 |
| 进制转换 | 2—36 进制、自定义进制、交换；有符号大整数，最多 4096 位，不支持小数 |
| 数字转中文 | 中文数字、金额大写；整数最多 16 位，中文小数最多 12 位，金额最多两位小数，不自动舍入 |
| 数字转上下标、迷你英文 | Unicode 数字／符号上下标、小型大写字母；字体显示依赖接收应用 |
| 摩斯电码 | 英文、数字、常用标点双向转换；不支持字符明确提示，单词用 `/` 分隔 |
| 拆分选词 | 汉字／英文词拆分、点选、全选、清空选择、复制／TXT 导出 |
| 中文转拼音 | 常见词组读音、声调符号／数字、无声调、首字母、多音字选择；保留非中文字符 |
| 渐变图 | 2—8 色、角度、颗粒、尺寸与比例；实际 PNG 预览与导出 |
| 九格切图 | 最大正方形裁切、水平／垂直定位、网格预览；ZIP 内含 1—9 顺序 PNG |
| GIF 合成与分解 | 2—60 张素材、帧排序、独立时长、统一时长、循环或只播放一次；分解生成 PNG 和时长表 ZIP |
| 表情制作、文字转图 | 拖动文字、描边、字体、颜色、照片背景、表情贴纸、画布尺寸、透明 PNG；透明预览有棋盘格，导出不带棋盘格 |
| 幻影坦克 | 两张图生成透明灰度 PNG，白／黑背景切换预览；其他应用处理透明度后可能改变效果 |
| 照片信息编辑器 | JPEG EXIF 查看、作者／版权／描述／拍摄时间修改、清除；文字编辑使用 ASCII。保留显示方向，不重编码图像像素，其他元数据如 XMP 不承诺清除 |
| OCR 图片文字识别 | 选择图片或 Android 拍照、整张／框选识别、识别框、可编辑文本、复制与 TXT 导出 |
| 拍照计数 | 明暗阈值与小区域过滤；分散、反差明显的圆片／硬币／颗粒标记；人工点按增删、带编号图片导出。粘连、遮挡和复杂背景需要校正，不是通用 AI 计数 |
| 视频提取音频 | 生成 M4A；Android 无重编码提取 AAC，其他音轨可先用原视频工具转换；Windows 用 FFmpeg 转 AAC。没有音轨明确报错 |

图片处理在独立计算线程进行。单张输入 30 MB、1600 万像素；渐变／文字画布最多 800 万像素。GIF 素材合计最多 60 MB、边长 64—640、帧时长 20—10000 ms；分解最多 120 帧／3200 万总像素。音频工具输入视频最多 100 MB，生成结果最多 64 MB。原件只读，所有修改另存新文件。

OCR 使用 Android 随包 ML Kit 中文识别模型，不依赖第一次使用时下载模型；Windows 使用系统中文 OCR 语言资源，没有资源时提供安装提示。模型会增加 Android 包体积，没有把 Windows 的 Python／FFmpeg 放进 APK。相机调用系统相机，通过只读写单个输出 URI 的 FileProvider 接收照片，不申请 CAMERA 或广泛相册读取权限。实体相机和各厂商系统的回调仍需补充验证。

所有工作内容和计分／计数仅保留在当前页面，不新增实验记录或自动保存。需要保留结果时主动导出；创作和识别工作台对未导出结果提供退出提醒。日常计时页面离开后结束本次会话。

## 验证与产物

- 静态分析无问题；138 项单元／界面测试通过。新增测试覆盖大整数、中文跨位零、金额精度拒绝、摩斯双向、拼音词组与 Unicode、九格顺序和像素、GIF 颜色／时长／真实 Flutter 播放次数、幻影坦克明暗合成、计数边界／噪点，以及全部 22 个工作台的窄屏布局。
- Android emulator-5558 实际 `ro.build.version.sdk=36`，三项原生／设备集成通过：中文英文 OCR；JPEG 信息修改和清除且像素／原件保持；真实 AAC 音频提取；文字卡片与秒表实际绘制。
- Windows 三项相同集成通过，另验证全屏进入与恢复；截图 `.buildlog/creative-poster-windows.png` 已查看。前期预览过高的问题已限制预览高度，保证首次进入可见文字。
- Windows 与 Android 的测试／构建应顺序执行，测试会生成平台的测试插件注册表，不能与正式构建同时写这些生成文件。测试或调试后正式构建保留默认的 pub 步骤，不使用 `--no-pub`，由 Flutter 按 release 模式重新生成注册表并排除测试插件。
- 开发产物放在 `dist/development/1.4.1/android/` 和 `windows/`，保留以前的正式包与 Windows 安装包。Android 包检查见 `android/inspection.json`，Windows 包均附 SHA-256。

主要源码：`lib/core/extra_text.dart`、`creative_images.dart`；`lib/features/extra_*`、`image_studio_page.dart`、`poster_page.dart`、`recognition_page.dart`；Android `CreativeService.kt`；Windows `worker.py` 和 `ocr.ps1`。入口加入主目录，图片工具下也有创作／识别分入口。

依赖：[image 4.10.1（MIT）](https://pub.dev/packages/image)、[lpinyin 2.0.3（BSD-2-Clause）](https://pub.dev/packages/lpinyin)、[ML Kit 中文识别](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)。Dart 包许可随 Flutter 开源许可页提供；模型按 Google 条款使用。

四种 Android 包和 Windows 安装版／便携版均已完成构建与检查。Windows 实际安装、重复安装、卸载、运行保护、924 个文件校验、用户偏好保留及两包五组后端验证全部通过；从搬迁后的 ZIP 自带解释器和 OCR 脚本实际识别成功。最终包体积与哈希见 [验收记录](ACCEPTANCE.md) 最后一节。

用户授权后版本已升至 **1.4.1+10**，当前包位于 `dist/development/1.4.1/`。Android 四包签名／SDK／架构检查通过，API 36 从旧正式包覆盖升级成功；Windows 新安装版和便携版验证通过。之前 1.4.0+9 开发包保留，最终哈希见 [验收记录](ACCEPTANCE.md) 最后一节。
