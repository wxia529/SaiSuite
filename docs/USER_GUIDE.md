# 使用说明 · v1.1.1

当前 v1.1.1 新增功能见 [v1.1 使用说明](V1_1_GUIDE.md)，安装包前缀为 `SaiSuite-1.1.1-`。下文保留原 46 项工具的操作说明。

## 安装与入口

将 `dist/SaiSuite-1.1.1-universal.apk` 复制到手机，通过系统安装界面安装。系统若要求允许该文件管理器安装应用，按系统提示设置。应用名称为「赛赛工具箱」。应用无需登录，计算与 PDF 处理在本地完成。

也可选择体积更小的独立架构包：设备支持 ARM64 时用 `SaiSuite-1.1.1-arm64-v8a.apk`；32 位 ARM 用 `SaiSuite-1.1.1-armeabi-v7a.apk`；x86_64 设备或对应模拟器用 `SaiSuite-1.1.1-x86_64.apk`。选择一个即可，功能完全相同；不确定设备架构时可以使用原通用包。

底部有主页、工具、收藏、设置。工具页可按分类和关键词搜索，支持常见别名，例如「拼 PDF」。点击星形收藏；收藏页长按拖动调整顺序。最近使用最多保留 20 项，计算器历史最多保留 30 条。设置支持浅色、深色、跟随系统，以及清除最近使用和计算器历史；清除记录会保留收藏。

## 计算、文本和科研工具

页面提供默认示例，可先直接点击「计算 / 处理」了解输出，再修改输入。字段名称标出单位；小数使用英文小数点。点击「清空」重置输入，「示例」恢复默认值。错误会显示在页面中，修正后重新计算。

原基础工具结果可复制、主动导出文件或调用 Android 分享；这些文件保存在用户选择的位置。普通输出为 UTF-8 JSON，包含工具、输入、结果、时间和适用条件，便于复核；密码生成仅导出密码本身，二维码保存为 PNG。密码和 Wi-Fi 信息不写入计算历史，二维码本身包含相应信息。

文本工具和 EC21 支持系统文件导入，UTF-8 文本上限 2 MB；文件 Hash 上限 100 MB，使用流式摘要。文本对比按行显示：`+` 新增、`-` 删除、空格为相同行；两侧行数乘积超过一百万时要求缩小文本。字符统计区分用户可见字符与 Unicode 码点。Hash 提供 MD5、SHA-1、SHA-256。

计算器支持括号、幂、常用函数、常数和角度/弧度模式；历史只保留表达式与结果。二维码容量受内容编码限制，过长输入会要求缩短。颜色支持 HEX、RGB、HSL。

摩尔质量支持元素、括号/方括号、小数计量与中点 `·` 表示的水合物。例如 `CuSO4·5H2O`；不支持电荷和同位素标记。标准原子量使用 CIAAW 2024 约化表，无标准值的元素使用 PubChem 参考质量数；结果页标出原子量与数据不确定度，但不进行不确定度传播。显示小数位不等于数据精度。配液工具可求称量质量、浓度或最终定容体积。

日期采用严格日历日期；日期推算支持年份 1—9999。时间戳可选秒或毫秒，日期转时间戳要求带 `Z` 或时区偏移。时区工具使用 IANA 时区；夏令时跳变中不存在或重复的当地时间会提示错误，需选择明确时间后换算。

## PDF 工作台

1. 从工具目录选择操作，点击「选择 PDF」或「选择 / 添加 PDF」，在系统文件选择器中选取文件。加密文件会要求输入已知打开密码。
2. 核对文件名、页数和预览。合并时长按文件排序；页面整理时长按页面排序，复制、删除和撤销均在页面列表中操作。
3. 如需选页，填写 `1,3-5`；留空表示全部，页码从 1 开始。指定序列保留填写顺序，重复页码合并；要复制页面请使用页面整理。
4. 点击「处理 / 查看」。批量拆分或图片导出显示当前页进度；处理中可取消。取消后可重新操作，处理中需先取消或等待完成再返回。
5. 点击「另存为」在系统界面选择目录和文件名。多份结果使用「保存 ZIP」，按输出顺序编号；系统负责同名文件的处理。也可点击「分享」选择接收应用。

默认只生成新文件，输入原件保持不变。点击「继续处理此文件」将单个输出作为当前文件；下方操作入口可携带当前文件进入另一个 PDF 工具。复杂文档请先查看输出再保存。PDF 页面整理缩略图按需渲染，预览失败时仍可尝试文件操作。

| 操作 | 选项与说明 |
|---|---|
| 合并 | 最多 30 份 PDF，输出总页数不超过 500 |
| 拆分 | 按单页、选中范围、每份固定页数；多份结果打包 ZIP |
| 提取 | 指定页码导出一个新 PDF |
| 整理 | 排序、复制、删除；保留至少一页；撤销最多 30 步 |
| 旋转 | 选中页顺时针 90 / 180 / 270°，保留其他页面 |
| 图片转 PDF | 最多 100 张 PNG/JPEG；A4 / Letter、横向、边距；等比居中 |
| PDF 转图片 | PNG / JPEG，72—300 dpi，实际长边最多 4096 px |
| 水印 | 文字或图片；上、中、下位置，大小与透明度；文字最多 128 字符 |
| 加密 | AES-256 打开密码，UTF-8 编码最多 127 字节；密码不保存 |
| 解密 | 必须知道打开密码，生成无密码副本 |
| 文字提取 | 提取文字层；扫描件与文字转曲文档提示需要 OCR |
| 信息 | 页数、大小、尺寸、旋转、元数据、加密、表单与签名标志 |

单文件上限 100 MB，输入与输出最多 500 页；ZIP 汇总原始结果上限 200 MB。图片解码会按需缩小到长边不超过 4096 px。上限是资源保护边界，复杂或高分辨率文件在内存较少的设备上仍可能需要减少页数；500 页验收采用文本样本，不代表任意 100 MB 文件均能处理。

页面重组不将原页整体栅格化。中文文字水印作为透明图像叠加，原页文字层保留；水印本身不可作为文字提取。水印位置按 PDF 原始页面坐标计算，旋转页请核对视觉方向。图片按解码像素方向导入，EXIF 方向未作自动校正，请先在相册确认方向。

修改可能使已有签名失效；不验证签名有效性。跨文档书签、复杂表单和批注关系不保证完整保留。不提供 OCR、压缩、PDF 转 Word、正文编辑、证书解密或 JPEG2000 可选解码。

临时文件在退出工作台时清理；未正常退出的应用生成缓存超过一天后会在下次启动清理。另存为的用户文件不会被自动清理。

## 十项电化学扩展的口径

| 编号 | 使用要点 |
|---|---|
| EC01 | 圆片/矩形/环形，输出单面几何面积；不等同于 ECSA |
| EC02 | 电流与容量按活性质量或几何面积归一化，集流体和非活性组分需扣除 |
| EC03 | `q=nF/(3.6M)`；电子转移数由用户根据配平反应确认 |
| EC04 | 同时显示面容量比与有效总容量比，容量需来自一致测试条件 |
| EC05 | 干固体配比合计 100%；计算时扣除粘结剂溶液自带溶剂 |
| EC08 | E/C 同时输出 µL/mAh 与 g/Ah；E/S 使用硫活性质量 |
| EC09 | 多组分质量比或体积比；体积可加仅为近似，最终体积需实测 |
| EC14 | 参比 vs SHE 偏移由用户输入校准值；RHE 换算使用温度和 pH，假设标准氢压 |
| EC16 | 氧化电流为正，仅扣除未补偿部分，避免重复 iR 校正 |
| EC21 | CSV/TSV 两列为时间 s、电流 mA，可含表头；严格递增时间，线性插值梯形积分，交零点分段 |

科研输出用于复核输入和模型。没有仪器控制、自动实验设计或未排期的曲线拟合功能；其余候选见电化学规划。
