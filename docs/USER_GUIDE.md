# 使用指南

本文说明当前版本的操作方式；逐版变化见 [发布记录](releases/README.md)。

## 安装、导航与更新

Android 支持 7.0／API 24 及以上；从 [GitHub Releases](https://github.com/wxia529/SaiSuite/releases) 选择 Universal 或设备对应架构的 APK。后续覆盖升级保持同一架构。Windows 支持 10／11 x64；安装版按中文向导选择目录，便携版必须完整解压再运行 `saisuite.exe`，无需另装 Java、Python 或 FFmpeg。

主页提供常用入口，工具页按分类、名称、关键词或编号搜索；星形按钮收藏入口，收藏页可调整顺序。最近使用保留入口，计算器历史保留普通计算，不承担实验记录管理。设置提供浅色、深色、跟随系统、历史清理及更新检查。

自动检查更新默认开启，每 24 小时最多发起一次请求，设置可关闭；手动检查可立即重试。有更新时查看说明，点击加速下载后由浏览器下载，再按系统安装流程升级。Windows 优先提供安装版，旧发布没有安装版时提供 ZIP；下载元数据仍来自 GitHub。

Windows 安装程序默认安装到当前用户目录，可选桌面快捷方式；更新前关闭应用。卸载保留用户偏好、主动导出的文件和用户自行加入安装目录的文件。

## PDF

选择 PDF 后查看页面预览，在工作台完成操作，再另存结果。页面预览支持全屏翻页与缩放，网格支持多选、全选、反选；整理页序时可排序、复制、删除和撤销。页面编号从 1 开始，范围可写为 `1-3,5`。加密输入需要已知打开密码。

| 操作 | 使用方式 |
|---|---|
| 合并／拆分／提取 | 添加文件、调整顺序，或选择页码和拆分方式；多份输出可打包 ZIP |
| 整理／旋转 | 使用网格与页序列表调整页面，对所选页面应用旋转 |
| 图片转 PDF | 图片排序后选择 A4、Letter 或“按图片尺寸”；后者每张独立生成一页，允许页面尺寸不同 |
| PDF 转图片 | 选择页码、格式和清晰度，预览后保存图片或 ZIP |
| 水印 | 设置内容、位置、大小、透明度和页面范围，先预览再导出 |
| 加密／解密 | 写入 AES-256 打开密码，或使用已知密码导出无密码副本 |
| 文字／信息 | 提取已有文字层，查看页数、页面尺寸、元数据及加密状态 |

“按图片尺寸”采用 EXIF 方向校正后的像素宽高，1 px 对应 1 PDF 点（72 dpi）；不裁切、不加边距、不重采样，PNG 保留透明度。它保留像素尺寸，不按照片打印 DPI 推算纸张毫米数。单张最多 1600 万像素、长边 14400 px；每批最多 100 MiB 文件和 6400 万像素，超限会提示。

常规 PDF 输入不超过 100 MiB、500 页，输出最多 500 页。大图和复杂页面可能需要分批处理；预览长边受限，不能用预览清晰度衡量原 PDF。页面重组保留页面内容流，但复杂书签、表单和批注关系不保证完整保留。修改可能使原有签名失效，本应用不验证签名；扫描 PDF 不提供 OCR，也不直接编辑正文、转 Word 或证书解密。

## 图片、图文与识别

图片工具按单张处理、多张拼图、创作与识别分入口。所有结果另存，导入原件保持不变。

| 工作台 | 操作要点 |
|---|---|
| 全屏图片编辑 | 裁剪、调整、滤镜、箭头／形状、文字、模糊／马赛克；图层可移动缩放，顶部撤销、重做、导出设置和另存为，按住按钮查看原图 |
| 拼图／长图 | 选择模板，长按换位，点按单格拖动缩放取景；调整间距、边距、圆角和背景，长图保留各图比例 |
| 图文制作 | 选择文字、图片或贴纸编辑模式；拖动文字与贴纸，缩放图层，可输入或粘贴自定义 emoji。首次导入照片采用照片比例，也可自定义画布 |
| 九格切图 | 横图、竖图均可拖动和缩放裁切，按编号预览，导出 ZIP 内的顺序 PNG |
| GIF 合成／分解 | 素材排序、逐帧时长、完整保留或填满裁切、循环次数；分解生成 PNG 帧和时长表 |
| 渐变图 | 选择多色、角度、颗粒与画布尺寸，预览并导出 PNG |
| 幻影坦克 | 两张图分别取景，统一比例，切换黑／白背景查看效果；其他应用重编码透明图后效果可能变化 |
| 照片信息 | JPEG EXIF 查看、修改或清除，文字字段使用 ASCII；保留显示方向和图像像素，不承诺清除 XMP 等所有元数据 |
| 图片 OCR | 导入图片或 Android 系统相机拍照，整张／框选识别；识别结果可编辑、复制或导出 TXT |
| 拍照计数 | 调节明暗阈值和区域大小，查看标记并人工增删；适合分散、反差明显的硬币、圆片和颗粒，粘连、遮挡及复杂背景需校正 |

全屏编辑输入最多 30 MB、4000 万像素，工作副本最长边不超过 4096 px；大图可能缩小。JPEG／PNG 导出可选择最长边 1024、2048、4096 px，不放大小图；PNG 保留透明，JPEG 填白。图文与画板的选中框、棋盘格不进入导出图片。图文贴纸最多 20 个，每个最多 24 个用户可见字符；彩色 emoji 随包提供后备字体。

拼图每次 2—9 张，工作图长边最多 1536 px；导出宽度最高 1080 px、高度最多 8000 px、最多 1600 万像素，超限整体等比缩小。创作工作台一般限制单张 30 MB、1600 万像素，渐变／图文画布最多 800 万像素。GIF 合成 2—60 张、素材合计最多 60 MB、边长 64—640 px、帧时长 20—10000 ms；分解最多 120 帧／3200 万总像素。

Android OCR 模型随包提供；Windows 使用系统中文 OCR 语言资源，缺少时按提示安装。拍照调用系统相机，不是连续相机识别，也不是通用 AI 计数。

## 视频、画板与配色

视频工作台内嵌播放器，拖动时间轴定位，通过双滑块或时间输入选定片段，可循环预览。截帧先展示实际输出图片再保存；时间轴缩略图只作定位参考。剪辑、静音、分辨率与码率设置生成 MP4（H.264／AAC），单个视频最多 500 MiB，实际格式支持取决于设备编解码器。

音频提取生成 M4A。Android 直接提取 AAC 音轨，其他音轨可先通过视频工具转换；Windows 转为 AAC。无音轨会报错，此入口输入最多 100 MB，结果最多 64 MB。

画板支持笔触、真实擦除、直线、箭头、形状、可移动文字、撤销／重做与透明背景。双指缩放和平移，或切换移动模式；全屏工具栏可收起，导出 PNG。最多 1000 笔，每笔最多 10000 个采样点，不自动保存作品。

配色助手支持预设、随机生成、锁定颜色、拖动排序、HEX 编辑和 PNG 色卡。取色器导入图片后用定位圆环与像素放大镜取色，也可提取照片主色带入配色助手。照片主色是采样统计结果，颜色数量和结果会随图像变化。

## 计算、文字与日常

科学计算器提供点按键盘、可编辑表达式、常用函数和角度／弧度模式；确认单位和模式后计算。单位换算、百分比、随机选择、密码与二维码使用各自工作台。密码默认 14 位；Wi-Fi 二维码包含网络凭据，导出前确认分享对象。

文本功能包含字符统计、格式整理、对比、摘要、编码、JSON、颜色码，以及只去除中英和中文与数字之间空格的整理。文件摘要输入最多 100 MB，UTF-8 文本导入最多 2 MB；文本对比按行显示变化。

扩展文字功能支持大整数进制、中文数字／金额大写、上下标、摩斯电码、迷你英文、拆分选词与拼音。金额最多两位小数，不自动舍入；摩斯仅支持其明确列出的字符，拼音提供多音字选择。

全屏时间屏幕和手持弹幕可调整字体、配色、方向和速度。秒表支持分段，计分支持撤销，反应力测试会识别抢跑；这些页面退出后结束会话。番茄钟在到时提醒，但通知权限、系统省电和休眠会影响提醒，Windows 关闭程序后无法提醒。

日期按严格日历处理；时间戳可选择秒或毫秒，日期转时间戳使用明确时区；夏令时跳变或重复时间按提示处理。

## 科研与电解液

科研栏目聚焦明确输入条件的即时计算：摩尔质量、配液、稀释、C-rate、载量与面容量、能量、几何面积、容量归一化、理论容量、N/P、浆料、E/C 与 E/S、溶剂配比、参比换算和 iR 校正。采用的公式与常量见 [科研口径](SCIENCE.md)。

电解液目标配方与实际称量反算分模式显示。溶剂、盐、添加剂使用可增删卡片，每个参数独立输入，结果实时更新；无效输入定位到对应字段并隐藏旧结果。检查盐纯度、浓度口径、最终密度和溶剂比例，再复制称量清单或主动导出。

mol/kg 按溶剂质量计，mol/L 按最终溶液体积计，wt% 按最终电解液质量计；体积目标需要密度，实际反算只有提供实测最终体积时才输出 mol/L。溶剂体积可加只是近似，不推断真实混合密度。纽扣电池备料按电池数量、单颗用量与余量计算；测试参数与电导率工具要求用户确认面积、参考容量和电阻来源。

不保存实验记录、配方历史或样品数据库，也不提供 CSV 曲线分析。退出前需要留存的输入与结果请主动导出，应用内临时缓存不能作为记录保管位置。

## 设备、导出与退出

Android 指南针、水平仪与传感器取决于设备硬件；缺失时显示不可用。指南针输出磁北，需要按提示校准；水平仪可归零。Windows 不显示这些手机传感器入口。两端的屏幕标尺都需要实体尺校准，系统 DPI 不等同于屏幕实际毫米尺寸。

保存成功以系统实际写入成功为准，取消或失败不算导出。创作和科研页面的未导出内容离开前会提示；保存的新文件位于用户选择的位置。工具缓存会在结束或后续启动时清理，用户主动导出的文件不会被当作缓存清除。
