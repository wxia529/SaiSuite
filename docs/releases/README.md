## 维护规则

- 文件名为 `vX.Y.Z.md`，正文写明完整应用版本和基础构建号；同一应用版本的构建修订在该文件中分段记录。
- 说明面向用户，写实际功能变化、修复、兼容条件和升级事项，不复制任务聊天、候选规划或全部开发日志。
- 准备时标注待发布；只有 GitHub 正式 Release 公开后才在索引记录已发布、实际发布日期、tag 与链接。
- 每次发版同步源码版本、发布文件和索引。不要补写无法核实的旧版发布日期，不改写历史 commit 信息。
- 文件体积与哈希来自实际发布附件，不复用本地旧包信息；技术验证留在检查日志和开发指南中。

新增说明可沿用以下结构：

```markdown
# SaiSuite X.Y.Z

应用版本：X.Y.Z+BUILD。

## 改进与修复

- 本版实际变化。

## 兼容与升级

平台支持、安装包选择，以及本版必须说明的限制。
```
