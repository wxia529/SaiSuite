# SaiSuite 1.4.1

应用版本：1.4.1+10。Android 82 项工具，Windows 79 项工具。

## 新增工具

- 时间屏幕、手持弹幕、分段秒表、记分牌和反应力测试。
- 进制转换、中文数字／金额大写、上下标、摩斯电码、迷你英文、拆分选词和中文拼音。
- 多色渐变、九格切图、GIF 合成／分解、表情制作、文字转图、幻影坦克和 JPEG 照片信息编辑。
- 中英文图片 OCR、框选识别与文本导出；拍照计数支持阈值调节和人工增删标记。
- 视频提取音频，输出 M4A。

## 工作台与 Windows

- 单张图片全屏编辑；电解液组分卡片与实时计算；拼图模板、逐格裁剪和长图拼接。
- 配色锁色、排序、照片主色与色卡导出；画板缩放、真实擦除、形状、文字和透明背景。
- 视频内嵌预览、时间轴和片段循环；PDF 全屏预览、多选页面，图片可按各自尺寸生成 PDF 页面。
- Windows x64 中文安装版与 ZIP 便携版，保留用户偏好及主动导出的文件。

## 使用说明

Android 随包提供中文 OCR 模型；Windows OCR 需要系统中文语言资源。拍照计数适合反差明显且分散的圆片、硬币或颗粒，粘连遮挡需手动校正。照片信息编辑支持 JPEG，文字字段使用 ASCII；修改结果另存，保留原件。Android 直接音轨提取支持 AAC，其他编码可先使用视频工具转换。

最低支持 Android 7（API 24），targetSdk／compileSdk 36。提供 universal、armeabi-v7a、arm64-v8a 和 x86_64 四种 APK，沿用原签名；同架构新版可覆盖升级。Windows 10/11 x64，Windows 程序未进行 Authenticode 签名。

不新增实验记录或自动保存；需要保留结果请主动导出。
