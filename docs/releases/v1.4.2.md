# SaiSuite 1.4.2

应用版本：**1.4.2+11**。本版更新说明整理于 2026-10-05。

## 改进与修复

- 表情制作与文字转图合并为“图文制作”。文字和贴纸可拖动、缩放，支持输入或粘贴自定义 emoji；旧收藏和最近使用入口自动迁移。
- 图文背景首次导入采用照片比例；九格切图、GIF 逐帧和幻影坦克双图支持横图／竖图拖动缩放取景，避免固定正方形裁切。预览与导出使用一致的裁切参数。
- 加入随包彩色 emoji 后备字体，改善 Windows 对较新 emoji 的显示和导出。
- 修正科学计算器“表达式”标签的位置，窄屏聚焦和输入时保持稳定。
- Android 与 Windows 统一采用青绿色图标：左上、左下、右下三个浅色方块，右上浅绿色闪电。安卓提供自适应和单色主题图标，Windows 程序与安装器使用相同标识。
- 更新下载按钮使用 gh-proxy.org 加速，覆盖 Android APK、Windows 安装版和便携版；更新查询与发布页继续使用 GitHub。
- 首页、工具列表和关于页面去除工具数量文案，Windows 随包说明同步调整。
- 重写 README，合并零散使用和开发说明，删除已放弃的电化学候选规划，建立统一的正式发布文档。

## 兼容与升级

Android 最低支持 7.0／API 24，compileSdk／targetSdk 为 36。提供 Universal、ARM32、ARM64 与 x86_64 APK，沿用原签名；升级请选择与已安装版本相同的架构。Windows 提供 10／11 x64 安装版与 ZIP 便携版；升级前先关闭应用，便携版需要完整解压。

文件处理继续保留导入原件。科研配方、创作内容与计数结果不提供自动保存或实验记录保管，需要留存请主动导出。已有配液、电解液和纽扣电池计算继续维护，不增加 CSV 曲线分析。

Android OCR 模型随包提供，Windows OCR 需要系统中文语言资源。Windows 程序未使用 Authenticode 签名；Android 签名密钥仅用于 APK。各安装包校验值以本次实际发布附件为准。
