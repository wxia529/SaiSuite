# SaiSuite 1.4.3

应用版本：**1.4.3+12**。本版更新说明整理于 2026-10-05。

## 改进与修复

- 移除“幻影坦克隐藏图”功能，同步清理首页搜索、图片工具入口及使用说明。
- 自动清理收藏和最近使用中的旧功能快捷入口，保留其他工具的顺序与设置；已导出的图片文件不受影响。
- 改进发布流程：直接使用草稿 Release ID 上传和发布，避免创建草稿后再次查找失败；上传完成并核对完整附件后才公开。

## 兼容与升级

Android 最低支持 7.0／API 24，compileSdk／targetSdk 为 36。提供 Universal、ARM32、ARM64 与 x86_64 APK，沿用原签名；覆盖升级请选择与已安装版本相同的架构。Windows 支持 10／11 x64，提供安装版与 ZIP 便携版；升级前关闭应用，便携版需要完整解压。

版本已准备，正式安装包与校验值以 GitHub Release 实际发布附件为准。
