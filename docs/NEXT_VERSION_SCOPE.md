# 下一阶段开发范围

更新日期：2026-10-04。v1.3.1 按用户要求删除四项桌面数据处理工具，当前为 60 个入口。保留配液、备料、参数和电导率计算；未开始 Windows 开发。实际范围见 [v1.3.1 范围调整](V1_3_1_GUIDE.md)。

## 用户约束

- 面向锂电电解液配制与纽扣电池实验，先做计算和即时分析。
- 暂不实现实验记录、配方收藏、试剂批次管理、电池编号、装配卡、检测记录与依赖内部历史的样品对比。
- 新科研工具不自动保存输入、结果、导入数据或实验历史；退出后不承诺恢复。需要留存时由用户主动通过系统保存界面导出文件，仅在实际写入成功后提示成功，取消和失败不算成功。
- 原始文件只读，导出生成新文件；临时工作文件不作为用户记录的存储位置。未导出内容离开页面前提示，用户可选择继续编辑、导出或放弃。
- 设置、收藏入口、标尺校准和番茄钟运行状态与实验记录分开。保存非实验设置不意味着提供实验记录保管功能。
- 用户新增要求：点按计算器、配色助手、番茄钟、画板、图片工具、视频工具、取色器、指南针、水平仪等传感器工具及标尺。
- 正式交付继续同时提供带 `universal` 标识的通用包和 arm64-v8a、armeabi-v7a、x86_64 三个独立包。

## 日常工具的最低可用范围

图片、视频与“其他传感器”的子功能先采用下表作为实施基线，允许按后续用户反馈调整。复用既有工具的升级不重复计数。

| 工具 | 最低可用功能 | 验收重点 |
|---|---|---|
| 点按计算器（升级 C01） | 数字、小数点、四则、括号、清空、退格、等号；科学函数、角度/弧度与表达式编辑 | 真正可点按的键盘，窄屏无溢出；按钮与表达式使用同一计算引擎，保留既有能力 |
| 配色助手（扩展 T08） | HEX/RGB/HSL、实时预览；互补色、类似色、三色组合；整组复制 | 区分配色建议与对比度检测；各颜色可以单独复制，不要求收藏方案 |
| 取色器 | 导入图片、放大并点选像素，显示色块与 HEX/RGB | 按原图像素取样，处理图片方向与坐标；首期不承诺跨 App 悬浮取色 |
| 番茄钟 | 可调整专注、短休息、长休息及轮数，开始、暂停、继续、跳过、重置；到时提醒 | 使用截止时间计算剩余时长；前后台切换、锁屏、通知拒绝、进程重建分别验证；不做统计历史，不把普通倒计时当作实验定时保障 |
| 画板 | 笔触、颜色、粗细、橡皮、撤销/重做、清空；PNG 导出 | 可点按及拖动绘制，撤销边界正确；离开未导出画布时提示，不依赖内部作品库 |
| 图片工具 | 裁剪、缩放、旋转/翻转、压缩、JPEG/PNG 转换、拼图、文字水印、文件信息 | 预览后另存新文件；方向、透明度、输出大小及大图内存验证，格式能力明确 |
| 视频工具 | 文件信息与预览、截取时间段、静音、截帧、分辨率/码率调整 | 可取消、显示进度、保存新文件；音画同步、方向、输出时长、编码支持及超限处理验证 |
| 指南针 | 磁北方向、方位角、传感器精度状态及校准提示 | 缺少所需传感器时明确不可用；首期不需要定位权限，不宣称输出真北 |
| 水平仪 | 双轴倾角、气泡显示、归零与重置校准 | 横竖屏坐标处理正确；已知水平面与倾角实测验证，标明手机测量口径 |
| 传感器工具 | 传感器清单及实时读数；在设备支持时显示照度、气压、磁场、加速度与角速度 | 每项检测是否存在并展示单位；不可用时不造数据；后台停止无必要的采样；气压高度只在有参考气压时作为估算 |
| 屏幕标尺 | mm/cm/in 刻度、横竖方向、双标记测距、手动实体尺寸校准 | 区分逻辑像素与物理尺寸；校准后核对已知长度，旋转后刻度正确，注明有效屏幕测量范围 |

首期视频以基础剪辑与文件处理为目标。先评估 Android 原生媒体能力与 Media3 Transformer，实测格式与编码器；不预先引入覆盖大量格式的庞大原生库。新增依赖前比较许可证、维护状况、APK 体积及三种 ABI 支持，完成后重新报告包体变化。

## 电解液与纽扣电池工具

| 工具 | 最低可用功能 | 计算与数据约束 |
|---|---|---|
| 多盐、多添加剂配方计算 | 多组分称量表、纯度修正、实际称量反算 | mol/L 以最终溶液体积为基准，mol/kg 以溶剂质量为基准；wt% 明确分母；无必要密度时不自动混算质量与体积 |
| 装电池备料计算 | 电池数量、单颗加液量、自定余量、每颗耗材数转成总用量 | 不从电池型号猜加液量或装配方案；余量由用户输入，明确是百分比还是固定量 |
| 测试参数换算 | mA/cm²、mAh/cm² 与面积换算电流、容量和时长，整合既有 C-rate | 面积、质量、容量及单位基准明确，零分母与非法参数拒绝 |
| 电解液电导率换算 | 电导池常数与实测体相电阻换算，支持已知几何尺寸口径 | 输入电阻与常数的来源由用户核对，输出 S/cm、mS/cm 并保留温度输入；不将整颗电池总阻抗直接当作电解液体相电阻 |

已有面积、归一化、E/C、溶剂配比和 C-rate 继续复用。循环数据分析、锂金属测试分析、电流积分与容量、梯度配方已从手机版删除，后续不自动纳入手机版范围。

## 实施顺序与完成条件

1. 点按计算器、配色助手、图片取色、番茄钟、画板。
2. 指南针、水平仪、实时传感器、可校准标尺。
3. 基础图片与视频处理，验证内存、进度、取消、文件导出和包体大小。
4. 无实验记录的配方、备料、参数与电导率计算。

每阶段完整实现目录入口、界面、错误反馈和必要验证，再进入下一阶段；不将演示读数、占位页面或未成功导出的结果计为完成。传感器与视频至少需要对应真机验收；模拟器或缺少硬件的设备只能证明可用性检测与错误处理，不能证明实际测量准确性。

## 技术参考

- [Android 传感器概览](https://developer.android.com/develop/sensors-and-location/sensors/sensors_overview)：设备传感器配置不同，运行时检查并处理缺失硬件。
- [Android DisplayMetrics](https://developer.android.com/reference/android/util/DisplayMetrics)：屏幕尺寸相关参数；标尺另设实体尺寸校准步骤。
- [Media3 Transformer](https://developer.android.com/media/media3/transformer)：Android 原生媒体编辑与导出能力参考，具体支持范围需实测。
- [NIST 浓度与质量摩尔浓度定义](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-8)：明确溶液体积、溶剂质量与质量分数的口径。
