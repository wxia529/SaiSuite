# 工具工作台升级

本轮继续使用 **1.4.0+9**，沿用 60 个工具入口，不新增实验记录、自动保存配方或历史数据。正式发布文件与开发验证安装包分开存放。

## 电解液配方

目标配方与实际称量反算分别展示相关参数。溶剂、盐、添加剂使用可增删卡片，每组最多 10 个组分；名称、摩尔质量、质量比、浓度、纯度各自输入。输入变化立即重算，错误出现时隐藏上一份结果；空值、非有限数值、纯度范围与重复名称显示在对应字段。

结果包含各组分称量、总质量、溶剂质量和溶剂质量比例。mol/L 或最终体积口径仍要求实测最终溶液密度；不推断密度、杂质组成或试剂形态。沿用原计算公式，另补充质量比与实际质量合计溢出的拦截。复制清单和退出时手动导出文本由用户决定，编辑过的内容离开前提示。

## 图片拼图

从图片工具的多张图片入口进入独立拼图工作台，支持双列、三列、横排、竖排和长图拼接。长按格子换位，点按格子进入拖动和双指缩放裁剪；取消恢复裁剪前状态。间距、边距、圆角、背景即时预览。

预览与 PNG 导出共用 `CollagePainter` 和同一份布局、裁剪参数。长图保留每张图原始比例。导出最高宽度 1080 px，最大高度 8000 px、最多 1600 万像素，超限整体等比缩小。每次 2—9 张，每张最多 30 MiB、4000 万像素；导入先由原生代码归一 EXIF 方向，工作图最长边限制 1536 px，限制编辑内存。原图只读，输出另存。

## 配色助手与取色器

配色支持 2—8 色、单色 HEX 修改、逐色锁定、长按换位、保留锁定颜色的随机生成，以及带 HEX/RGB 的 PNG 色卡导出。保留原有 12 组预设、HEX/RGB/HSL 基色输入与对比度参考。照片中只有一个有效主色时也可带入助手，再添加颜色。

取色器保留圆环和像素放大镜，新增照片主色提取与带入配色助手。提取在独立 isolate 中执行：最多采样约 20000 个像素，按量化色桶人口排序、合并近似颜色，忽略 alpha 小于 128 的像素；不包含模型。照片主色与设计配色分别标明来源。精确取色仍限制图片最多 20 MiB、1600 万像素。

## 画板

支持双指缩放、移动模式、重置视图、平滑笔触、直线、箭头、矩形、椭圆与可拖动文字。第二根手指加入时撤回该手势的初始笔触，恢复此前撤销状态，避免缩放留下误画。

橡皮在独立图层使用 `BlendMode.clear`，真正擦除像素；白色背景是图层下面的背景，透明背景用棋盘格显示，棋盘格不进入 PNG。透明背景切换、图形、文字添加与移动均可导出；文字移动通过同一文字标识的后续操作覆盖前一位置，撤销后恢复原位置。全屏工具栏可以收起，视图变换不改变固定导出坐标。

仍限制最多 1000 笔、每笔 10000 个采样点。没有自动保存作品。

## 视频

使用 Flutter 官方 [video_player](https://pub.dev/packages/video_player) 2.14.1 内嵌播放，保留原生 Media3 Transformer 导出。支持播放器时间滑块、6 张缩略图时间轴、原有剪辑范围双滑块和精确时间输入、选中片段循环。拖动定位合并为约 80 ms 的请求，并串行执行；缩略图依次解码、最长边不超过 320 px。

缩略图使用附近关键帧，仅用于定位参考。截帧使用 `OPTION_CLOSEST`，生成后显示实际输出 PNG 再另存；播放器不是最终截图。导出设置仍单独收纳在“画质与声音”。关闭页面清理缩略图，应用进入后台暂停预览。

单个视频最多 500 MiB，输出 MP4（H.264/AAC）；设备解码器、编码器决定格式可用性。API 36 模拟器测试不能替代真实设备的性能、声音与同步检查。

## PDF

保留既有 PDFBox 工具，不接回高级 PDF 编辑原型，不增加相关依赖或字体。支持全屏左右翻页、双指缩放、缩略图网格、全选/清空/反选和多选应用。

提取、旋转、转图片、水印等操作可用网格填写页面范围；页面整理的网格按当前页序选择保留的页面，保留重复页的独立出现位置，原有拖动排序、复制、删除与撤销继续可用。空选择不能应用，取消不修改页序或范围。预览按需生成，缩略图 40 DPI、全屏 120 DPI，原生渲染长边最多 4096 px。预览不代表原 PDF 内容被修改。

## 验证与交付

设备以实际 `adb devices` 和 `ro.build.version.sdk` 为准，默认 `SaiSuite_API_36`（Android 16）。新增 `test/tool_upgrades_test.dart`，覆盖颜色透明度与排序、拼图几何、真实擦除、无效配方输入、锁色、双指手势和 PDF 空选择。

`tools/test_tool_upgrades.ps1` 准备 Flutter 官方 bee.mp4 视频样例，安装调试包后将样例复制到应用缓存，再执行 `integration_test/tool_upgrades_test.dart`。集成测试覆盖拼图导出像素、原生 PDF 预览与重复页转换、原视频哈希、缩略图尺寸、实际截帧、内嵌播放与循环、剪辑时长及输出尺寸、临时输出清理。测试视频不进入正式安装包。

构建与验证结果写入 `.buildlog/tool-upgrades-*.log`。开发安装包存放于 `dist/development/tool-upgrades/`，包含 universal、armeabi-v7a、arm64-v8a、x86_64 四种；沿用原发布签名、最低 API 24 和目标 API 36。最终检查结果见该目录的 `inspection.json` 和 `SHA256SUMS.txt`。


本轮最终检查：`flutter analyze` 无问题，126 项单元/界面测试和 2 项 API 36 集成测试通过。四包均通过签名、版本、平台与 ABI 检查；原生 `.so` 集合与上一版图片编辑开发包一致。universal 为 79.12 MiB、armeabi-v7a 为 34.56 MiB、arm64-v8a 为 36.49 MiB、x86_64 为 38.03 MiB。相较上一版图片编辑开发包，arm64 增加约 0.59 MiB、universal 增加约 1.36 MiB。包内没有高级 PDF 字体和测试视频。


## 图片转 PDF：按图片尺寸

“图片转 PDF → 页面尺寸”新增“按图片尺寸”，默认仍为 A4。选中后隐藏横向纸张和边距，每张图片独立生成一页，页面尺寸采用方向校正后的像素宽高，1 像素对应 1 PDF 点（72 dpi）。例如 5000×200、240×480 两张图片生成对应的两种页面尺寸，不统一纸张、不裁剪、不加边距、不重采样；照片 EXIF 的八种方向会正确显示。此规则用于保留像素尺寸，不根据图片的打印 DPI 元数据推算纸张毫米数。

图片完整解码后无损封装到 PDF，JPEG 不进行再次 JPEG 有损压缩，PNG 保留透明通道；并非将原图文件字节原封不动装入附件。该选项每张最多 1600 万像素、长边最多 14400 px；每批输入文件合计最多 100 MiB、像素合计最多 6400 万，超限或内存不足明确提示，不偷偷缩小。A4 和 Letter 沿用原来的适配方式。

`tools/test_pdf_original_size.ps1` 在 API 36 上生成 10 页混合尺寸验证文件。独立 pypdf 解析确认所有页面与嵌入图像的尺寸、透明通道、EXIF 方向正确，测试图逐像素 RGBA 差异为 0；Poppler 72 dpi 渲染核对通过，输入 SHA-256 保持不变。127 项单元/界面测试与该项集成测试通过。日志与独立验证文件为 `.buildlog/pdf-original-size-*`。

本次开发包仍为 1.4.0+9，保存于 `dist/development/pdf-original-size/`，提供 universal 与三种 ABI，未覆盖上一批工作台开发包或正式发行包。
