## 公式登记

| 工具 | 公式 | 单位和条件 |
|---|---|---|
| S01 | M=Σ νᵢAᵢ | 化学式计量系数与原子量；g/mol |
| S02 | m=cVM；c=m/(VM)；V=m/(cM) | c 为 mol/L，V 为最终定容体积 L |
| S03 | c₁V₁=c₂V₂ | 同一种浓度口径，稀释不能提高浓度 |
| S04 | I=C-rate × Q | mAh × h⁻¹ 得到 mA，Q 为约定参考容量 |
| S05 / EC02 | 载量=m/A；面容量=mq/A；比容量=Q/m | 活性质量 mg 转 g，面积 cm² |
| S06 | E=hν=hc/λ；摩尔能量=NₐE | 波长与频率仅在光子关系下使用 |
| EC01 | 圆片 πd²/4；矩形 lw；环形 π(D²−d²)/4 | mm² 转 cm² 除以 100，单面几何面积 |
| EC03 | q=nF/(3.6M) | n 由配平反应确认；mAh/g，M 为 g/mol |
| EC04 | 面 N/P=qₙmₙ/(qₚmₚ)；总 N/P=Qₙ/Qₚ | 单位统一；有效面积不同则面比与总比不同 |
| EC05 | 总浆料=干固体/固含量；另加溶剂=总需溶剂−粘结剂溶液带入溶剂 | 质量分数；干固体比例合计 100% |
| EC08 | E/C=V/Q；E/S=V/mₛ | µL/mAh、µL/mg；密度换算 g/Ah |
| EC09 | 每组分量=总量×比例/比例总和；m=ρV | 用户提供密度；体积可加为近似 |
| EC14 | E目标=E原+Δ原−Δ目标；E_RHE=E原+Δ原+(RT/F)ln(10)pH | Δ 为相同条件下 vs SHE 偏移；标准氢气压力 |
| EC16 | E校正=E测得−IRᵤ(1−已补偿比例) | 氧化电流为正；mA 转 A；避免重复补偿 |

这些公式由相应的质量守恒、电荷守恒、几何关系或单位定义实现。参比换算的偏移不预置通用 Ag/AgCl 数值，由用户输入校准值与实验条件。首版没有材料属性数据库、活度修正、仪器自动读入或高级拟合。验证样例见验收记录和测试源码。


## 电解液计算

盐称量按有效盐质量/纯度计算；mol/kg 溶剂以溶剂质量计，mol/L 以最终溶液体积计，wt% 有效盐和添加剂均以最终电解液质量计。设溶剂质量 S、总质量 T、总添加剂质量分数 f。mol/kg 模式各盐称量为 S·cᵢMᵢ/(1000pᵢ)，由 T=S+Σm盐+fT 解出目标质量对应溶剂量；mol/L 或 wt% 模式盐为总质量的系数倍，S=T(1−f−Σkᵢ)。体积目标 T=ρV，mol/L 的 kᵢ=cᵢMᵢ/(1000ρpᵢ)。拒绝非正溶剂量及缺少必需密度。实际反算只在提供实测最终体积时输出 mol/L。

N03 总备液为电池数量×单颗 µL×(1+百分比余量)+固定 µL 余量。N04 I=jA、Q=qA、t=Q/I；C-rate=I/参考容量。N05 σ=K/R，几何口径 K=L/A，单位 cm、cm²、Ω，输出 S/cm 与 mS/cm，不推断体相电阻来源。


实现及质量守恒/错误边界样例在 `test/lab_test.dart`；计算结果仅由用户主动导出。当前支持范围见 [v1.3.1 范围调整](V1_3_1_GUIDE.md)。
