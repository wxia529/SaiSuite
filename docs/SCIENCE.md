登记日期：2026-10-04。实现位置 `lib/core/engine.dart`，原子量表 `lib/core/atomic_weights.dart`。结果记录包含工具版本、输入单位、结果和条件。

## 常量与数据

| 数据 | 应用采用值 | 来源与条件 |
|---|---|---|
| 法拉第常量 F | 96485.33212 C/mol | NIST CODATA 2022，取显示位数 |
| 摩尔气体常量 R | 8.314462618 J/(mol·K) | NIST CODATA 2022，取显示位数 |
| 温度偏移 | 273.15 K | 摄氏转绝对温度 |
| eV 与摩尔能量 | 1 eV ≈ 96.4853321233 kJ/mol | 由基本电荷与阿伏伽德罗常量换算 |
| 光子 hc/e | 1239.841984332 eV·nm | 由 Planck 常量、光速和基本电荷换算 |
| 原子量 | CIAAW 2024 约化标准表 84 项 | 采用表中中心值，保留不确定度；不传播不确定度 |
| 其他元素 | PubChem 参考质量数 34 项 | 无标准原子量，明确标注为参考质量数 |

常量依据 [NIST CODATA 完整表](https://physics.nist.gov/cuu/Constants/Table/allascii.txt)。原子量依据 [CIAAW 2024](https://ciaaw.org/abridged-atomic-weights.htm)，其余依据 [PubChem](https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON)。这些数值在应用中离线保存；天然或商业材料的同位素组成变化可能影响原子量，不把显示位数当作实验精度。

## 公式登记

| 工具 | 公式 | 单位和条件 |
|---|---|---|
| S01 | M=Σ νᵢAᵢ | 化学式计量系数与原子量；g/mol |
| S02 | m=cVM；c=m/(VM)；V=m/(cM) | c 为 mol/L，V 为最终定容体积 L |
| S03 | c₁V₁=c₂V₂ | 同一种浓度口径，稀释不能提高浓度 |
| S04 | I=C-rate × Q | mAh × h⁻¹ 得到 mA，Q 为约定参考容量 |
| S05 / EC02 | 载量=m/A；面容量=mq/A；比容量=Q/m | 活性质量 mg 转 g，面积 cm² |
| S06 | E=hν=hc/λ；摩尔能量=NₐE | 波长与频率仅在光子关系下使用 |
| EC01 | 圆片 πd²/4；矩形 lw；环形 π(D²−d²)/4 | mm² 转 cm² 除以 100，单面几何面积 |
| EC03 | q=nF/(3.6M) | n 由配平反应确认；mAh/g，M 为 g/mol |
| EC04 | 面 N/P=qₙmₙ/(qₚmₚ)；总 N/P=Qₙ/Qₚ | 单位统一；有效面积不同则面比与总比不同 |
| EC05 | 总浆料=干固体/固含量；另加溶剂=总需溶剂−粘结剂溶液带入溶剂 | 质量分数；干固体比例合计 100% |
| EC08 | E/C=V/Q；E/S=V/mₛ | µL/mAh、µL/mg；密度换算 g/Ah |
| EC09 | 每组分量=总量×比例/比例总和；m=ρV | 用户提供密度；体积可加为近似 |
| EC14 | E目标=E原+Δ原−Δ目标；E_RHE=E原+Δ原+(RT/F)ln(10)pH | Δ 为相同条件下 vs SHE 偏移；标准氢气压力 |
| EC16 | E校正=E测得−IRᵤ(1−已补偿比例) | 氧化电流为正；mA 转 A；避免重复补偿 |
| EC21 | Q=∫I dt；梯形线性插值；交零点分段 | mA·s / 3600 得到 mAh；1 mAh=3.6 C |

这些公式由相应的质量守恒、电荷守恒、几何关系或单位定义实现。参比换算的偏移不预置通用 Ag/AgCl 数值，由用户输入校准值与实验条件。首版没有材料属性数据库、活度修正、仪器自动读入或高级拟合。验证样例见验收记录和测试源码。
