# 电化学工具规划

更新日期：2026-10-04

关联文档：[开发指南](DEVELOPMENT_GUIDE.md)

## 1. 产品目标与范围

让赛赛工具箱成为实验前准备、实验后快速处理数据时可以随手打开的电化学工作台，覆盖电池、电解液、电催化、超级电容器和腐蚀研究的常见任务。

本次新增 50 项候选能力，编号 EC01—EC50。2026-10-04 用户已确认把第一批十项纳入当前交付，共计 36 个基础工具 + 10 个电化学扩展；其余 40 项继续保留在功能池。不同输入方式不重复计为已交付工具。

已有工具继续复用：S01 摩尔质量、S02 浓度与配液、S03 稀释、S04 C-rate、S05 电极载量与面容量、S06 科研能量换算。新增入口可以共享这些底层计算。

建议先做十项实验室日常计算，再建设文件导入和分析能力，最后实现对实验条件要求较高的模型。正式版本归属在排期时写回开发指南。

## 2. 优先级说明

- A：建议进入第一批电化学扩展，共十项，主要是明确输入条件的计算工具。
- B：常用扩展；其中涉及曲线的工具要先完成统一数据导入、选区与绘图。
- C：进阶模型；先验证公式、拟合方法与适用范围，再安排实现。

优先级不代表科学重要程度，也不等于确定的发布日期。

## 3. 五十项候选能力

### 3.1 电极设计与材料计算：8 项

| ID | 工具 | 主要输入与结果 | 优先级与实现注意 |
|---|---|---|---|
| EC01 | 电极面积与几何尺寸 | 圆片直径、矩形长宽、环形内外径；输出 cm²、mm² | A；区分几何面积、暴露面积、单面与双面 |
| EC02 | 电流与容量归一化 | 电流、容量、质量、面积；输出 mA/cm²、mA/g、mAh/g、mAh/cm² | A；明确活性物质质量与总涂层质量，复用 S05 |
| EC03 | 理论比容量 | 化学式、摩尔质量、每式量电子转移数；输出 mAh/g | A；电子数由用户或经核对的反应提供，不从化学式猜测 |
| EC04 | N/P 配平 | 正负极实测可逆比容量、载量、有效面积；输出容量比与目标负极质量 | A；区分总容量比与面容量比，不能按质量比直接计算 |
| EC05 | 浆料配方 | 活性物质、导电剂、粘结剂比例、固含量、粘结剂溶液浓度；输出各组分称量 | A；区分干固体质量与溶液质量，计入粘结剂溶液中的溶剂 |
| EC06 | 电极厚度与压实密度 | 去除集流体后的涂层质量、面积和干膜厚度；输出表观涂层密度 | B；支持单面或双面，湿膜厚度不直接代入 |
| EC07 | 孔隙率估算 | 干膜表观密度、组分质量比例、各组分真实密度；输出孔隙率 | B；基于固体体积可加的近似，缺少密度时不能给出确定值 |
| EC08 | 电解液用量与 E/C、E/S | 电解液质量或体积、容量、硫质量、密度；输出用量比与目标加液量 | A；显示 µL/mAh、g/Ah 或 µL/mg 等完整单位，不混用 E/C 与 E/S |

N/P 的计算必须保存所用容量的测试条件与归一化口径；不同面积的电极要分别计算有效总容量。面积相同时才能直接由面容量之比得到相同结果。容量配平是电极设计中的独立问题，可参照 [Warwick 收录的 N/P 与电极特性研究](https://wrap.warwick.ac.uk/id/eprint/169436/)。

| EC11 | 纯度与结晶水修正 | 试剂纯度、结晶水数、目标有效物质用量；输出称量质量 | B；使用相应水合物摩尔质量，杂质或含水数据必须有定义 |

### 3.3 电位、反应与动力学：7 项

| ID | 工具 | 主要输入与结果 | 优先级与实现注意 |
|---|---|---|---|
| EC14 | 参比电位换算 | 原参比、目标参比、温度、填充液条件、校准值；支持 SHE/RHE | A；常数必须有来源，RHE 还需 pH；支持自定义实测偏移 |
| EC15 | Nernst 方程 | 标准或形式电位、温度、电子数、反应商；输出平衡电位 | B；区分活度与浓度近似，反应商按配平反应构造 |
| EC16 | iR 校正 | 电位、电流、未补偿电阻、已补偿比例；输出电压损失和校正电位 | A；明确电流正负号及已有校正，避免重复扣除 |
| EC17 | 过电位 | 测量电位、参比信息、目标反应平衡电位；输出有符号过电位与幅值 | B；区分 HER、OER 或自定义反应，显示温度、pH 和电位基准 |
| EC18 | Faraday 电解与沉积 | 电量、电流时间、电子数、效率、摩尔质量；输出产物摩尔数或沉积质量 | B；反应化学计量必须由用户确认；厚度估算还需面积与密度 |
| EC19 | 法拉第效率 | 定量产物量、总电量、电子数；输出各产物 FE 与总和 | B；气体数据需温压和干湿基准，色谱数据需校准和流量信息 |
| EC20 | Tafel 分析 | 极化曲线与用户选定区间；输出 mV/dec、截距和拟合质量 | C；电催化单支拟合与腐蚀双支分析分开，不能自动取整条曲线 |

参比电极的具体条件会影响测量，预设不能只写一个名称和一个固定数字；应记录填充液、温度和校准信息。参见 [Gamry 参比电极说明](https://www.gamry.com/application-notes/instrumentation/reference-electrodes)。

iR 校正使用未补偿电阻，而不是任意电阻值；记录校正前后数据和补偿比例。参见 [Gamry iR 补偿说明](https://www.gamry.com/application-notes/instrumentation/understanding-ir-compensation/)。

Tafel 分析的区间需要考虑动力学控制和传质影响；软件必须让用户核对选区与模型。参见 [Gamry 电化学腐蚀测量说明](https://www.gamry.com/application-notes/corrosion-coatings/basics-of-electrochemical-corrosion-measurements/)。

### 3.5 CV、LSV 与瞬态分析：7 项

| ID | 工具 | 主要输入与结果 | 优先级与实现注意 |
|---|---|---|---|
| EC28 | 扫描参数与预计时长 | 起始/反转电位、扫描速率、循环数、静置段；输出总时长 | B；每段按实际扫描路径累计，区分 V/s 与 mV/s |
| EC29 | 峰位与峰电流分析 | CV/LSV 数据、扫描支路、基线；输出峰位、峰高、峰间距和峰电流比 | B；自动候选峰必须可人工调整，形式电位估计仅在相应可逆性假设下显示 |
| EC30 | CV 电荷积分 | 曲线、扫描速率、选区和基线；输出积分电荷 | B；保持扫描方向和电流符号，区分单支与整圈积分 |
| EC31 | Randles–Ševčík | 多扫描速率峰电流、浓度、面积、温度、电子数；估算扩散系数或面积 | C；明确溶液可逆体系和扩散假设，单位与温度条件不能遗漏 |
| EC32 | b 值分析 | 多扫描速率的对应电流；拟合 log|i| 与 log v | C；零值、符号变化与峰位漂移要处理；不能仅凭 b 值认定唯一储能机制 |
| EC33 | Dunn 分解 | 多扫描速率 CV；拟合 i=k₁v+k₂√v，输出贡献随电位变化 | C；分支对齐、插值、残差和异常系数可检查；作为所选模型下的分解 |
| EC34 | Cottrell 分析 | CA 时间—电流、浓度、面积、电子数；拟合 i 与 t^(-1/2) | C；明确平面半无限扩散条件，排除仪器瞬态和其他电流贡献 |

Randles–Ševčík 的温度通式与 25 ℃ 简化形式不能混用；简化常数依赖单位体系。实现时核对 [Pine Research 方程说明](https://pineresearch.com/support-article/randles-sevcik-equation/) 和 [CV 说明](https://pineresearch.com/support-article/cyclic-voltammetry-cv/)。

### 3.8 扩散、温度、旋转电极与腐蚀：4 项

| ID | 工具 | 主要输入与结果 | 优先级与实现注意 |
|---|---|---|---|
| EC42 | GITT/PITT 分析 | 脉冲与静置数据、时间、尺寸或模型参数；输出扩散系数估算 | C；区分方法与几何，检查稳态、欧姆压降、短时扩散和线性区间 |
| EC43 | Arrhenius 拟合 | 不同温度下的电导率、速率常数或扩散系数；输出活化能 | C；温度用 K，区分 ln σ 与 ln(σT) 等模型，不混合物理量 |
| EC44 | RDE/RRDE 与 K–L | 转速、盘/环电流、收集效率、溶液参数；输出动力学或产物相关量 | C；rpm 转 rad/s，区分 Levich、K–L 与 RRDE 的适用条件 |
| EC45 | 腐蚀速率与极化电阻 | 电流密度、当量、密度或 Rp 与 Tafel 参数；输出腐蚀速率 | C；明确均匀腐蚀假设、单位和合金当量，不直接覆盖局部腐蚀 |

GITT/PITT 不是只输入几个电压差就能保证得到材料真实扩散系数。分析必须保存模型与假设，检查脉冲区间和欧姆压降。参见 [BioLogic AN70](https://www.biologic.net/documents/determination-diffusion-coefficient-inserted-species-host-electrode-eis-pitt-gitt-techniques-an70/)。

旋转电极的角速度单位与模型选择可参考 [Pine 旋转电极用户指南](https://pineresearch.com/downloads/documents/DRU10158.pdf)。

### 3.9 电催化与界面专题：5 项

| ID | 工具 | 主要输入与结果 | 优先级与实现注意 |
|---|---|---|---|
| EC46 | Cdl/ECSA 与粗糙度 | 非法拉第区 CV 或特征吸附电荷；输出 Cdl、ECSA 或面积比 | C；方法、区间、材料特定参考常数和背景扣除要记录，不提供万能比电容 |
| EC47 | Butler–Volmer 与交换电流 | 温度、电子数、传递系数、j₀ 或曲线；先模拟，后评估拟合 | C；规定有符号电流、面积口径和过电位；含传质时不能直接套纯动力学模型 |
| EC48 | 离子迁移数估算 | 极化前后电流、界面电阻和电压；提供 Bruce–Vincent 类计算 | C；区分所用方法与近似条件，异常结果不裁剪成 0—1 |

## 4. 第一批建议实现的十项

选择：EC01、EC02、EC03、EC04、EC05、EC08、EC09、EC14、EC16、EC21。

### 实验前

电极面积 → 活性物质载量 → 理论/实测容量 → C-rate 电流 → N/P 配平 → 浆料配方 → 电解液配比与用量。

### 实验后

原始电流/电压 → 参比换算与 iR 校正 → 容量积分 → 质量/面积归一化 → 导出结果与计算条件。

第一批将 S01、S02、S04、S05 的既有计算和这些新增功能连起来即可；不需要先建设通用工作流引擎。

第二批建议优先 EC10、EC13、EC17—EC19、EC22—EC26、EC28—EC30、EC35、EC39—EC41、EC50，并按实际用户需求拆分迭代。CV 拟合、EIS 拟合和 GITT 等进入后续专题开发。

## 5. 核心公式与输入约定

本节用于约束实现口径，不替代工具实现时逐项核对公式来源。

| 计算 | 公式与单位约定 | 必须说明 |
|---|---|---|
| 圆片面积 | A=π(d/2)²；d 先统一为 cm | 暴露面积可小于圆片总面积 |
| 电流密度 | j=I/A | 几何面积与 ECSA 归一化分开 |
| 比容量/面容量 | q=Q/m；qA=Q/A | m 用 g，Q 用 mAh；记录质量口径 |
| 理论比容量 | qth=nF/(3.6M) | M 为 g/mol，n 为每式量电子数，结果 mAh/g |
| N/P | Qnegative/Qpositive | 两边均为相同条件下定义的有效可逆容量 |
| 活性物质质量 | mactive=mcoating×wactive | mcoating 已扣除集流体；wactive 为干固体质量分数 |
| 涂层表观密度 | ρbulk=mcoating/(A×t) | A 与 t 对应同一涂层；双面分开或明确合并方式 |
| 孔隙率估算 | ε=1−ρbulk/ρsolid；1/ρsolid=Σ(wi/ρi) | 固体组分体积可加近似；厚度是干膜厚度 |
| 浓度/质量 | c=n/Vsolution；m=nM | 溶液最终体积，非加盐前溶剂体积 |
| 离子强度 | Iionic=(1/2)Σ(ci zi²) | 与电流 I 区分命名；明确浓度和离解假设 |
| 电导率 | κ=Kcell/R；平板几何 Kcell=L/A | R 为所选模型的体相电阻 |
| 参比换算 | Enew=Eold+Eref,old(vs SHE)−Eref,new(vs SHE) | 参考值条件一致；标记液接电位等实际偏差 |
| SHE → RHE | ERHE=ESHE+(RT/F)ln(10)×pH | 按标准氢气压力、氢离子活度口径；温度用 K |
| Nernst | E=E°−(RT/nF)ln Qreaction | Qreaction 是配平反应的无量纲活度反应商 |
| iR 校正 | Ecorrected=Emeasured−I Ru | 本表采用氧化电流为正；已有部分补偿时只处理剩余部分 |
| 容量积分 | QmAh=(1/3.6)∫I(A)dt(s) | 分别积分充放电，保留时间轴和电流符号规则 |
| 能量积分 | EWh=(1/3600)∫V(V)I(A)dt(s) | 正值能量的方向约定明确，不能以末端电压代替完整曲线 |
| 库仑效率 | CE=Qdischarge/Qcharge×100% | 定义匹配充放电段；异常值保留并解释，不强制截断 |
| 能量效率 | EE=Edischarge/Echarge×100% | 与 CE 分开；电压效率可由匹配平均电压计算 |
| 法拉第效率 | FE=zF nproduct/Qtotal×100% | 产品摩尔数、电子数、电量及校准依据明确 |
| DCIR | R=abs(ΔV/ΔI) | 明确两个取点时刻和脉冲条件 |
| CV 电荷 | Q=∫I dt；单调恒扫速支路 dt=dE/vsigned | 扫描反转处分段，面积积分不自动取绝对值 |
| 理想恒流电容 | C=IΔt/ΔV | 合适的线性放电段，已明确压降和器件口径 |
| 理想电容能量 | EJ=(1/2)C(Vhigh²−Vlow²) | J 转 Wh 除以 3600；非理想情况优先积分 |

常数：F=96485.33212 C/mol，R=8.314462618 J/(mol·K)。实现统一 SI 内部计算，输入输出负责单位换算。有效数字按数据精度显示，不能因常数位数多而制造结果精度。

常量、材料属性与参比电位预设各有数据版本、来源、适用温度和条件。允许用户填写自定义测量值，但导出时要保留自定义标记。

## 6. 数据分析的共用基础

这些能力服务于所有电化学分析工具，不作为五十项候选中的额外工具计数。

### 数据导入

- 通用 CSV/TSV，支持列映射、分隔符、编码、表头和单位预览。
- 映射时间、电流、电压、容量、频率、阻抗、循环编号和步骤编号。
- 区分绝对时间、步骤时间、累计时间，以及每圈重新计时的数据。
- 保留原文件和原始数据；清洗、基线、平滑和筛选形成可追踪的处理步骤。
- 仪器专有格式与模板仅在真实样本验证后声明支持，不预先承诺兼容所有设备。
- 缺失值、重复点、非单调轴、突变和异常列名给出预览及处理选择。

### 图表与拟合

- 支持曲线叠加、颜色、轴单位、图例、缩放、选区和导出。
- 正反扫描、不同循环与充放电段有明确标记。
- 选区、基线、平滑、插值、权重、参数边界和优化器配置均可核对。
- 拟合输出参数单位、残差；可计算时提供参数不确定度，不能把高 R² 等同于物理机制正确。
- 对数据不足、拟合不收敛、病态参数和无效模型给出解释，不用一个数字掩盖失败。
- 批量处理以前一次验证成功的单文件流程为基础，用户可核对每个文件的结果。

### 结果记录与导出

- 保存样品名称、活性物质质量、面积、温度、参比、扫描速率、窗口、循环和归一化口径。
- 保存工具版本、公式/数据版本、输入单位、处理参数与结果。
- CSV 结果和 PNG/SVG 图像根据实际实现能力提供；报告 PDF 后续评估，并与现有 PDF 文件处理区别开。
- 本地实验记录支持复用参数和对比样品，首期不需要云端账户或仪器远程控制。

## 7. 验收样例与错误检查

以下是自行计算的合成样例，用于验证实现和单位换算，不来自某个实际实验。对应工具实现时补充独立核对与边界测试。

| 场景 | 输入 | 应有结果或行为 |
|---|---|---|
| 圆片面积 | 直径 12 mm | 约 1.13097 cm² |
| 归一化 | 活性物质 2 mg、容量 0.32 mAh | 160 mAh/g；不能把 2 mg 当 2 g |
| 理论容量 | M=157.76 g/mol，n=1 | 约 169.89 mAh/g |
| N/P | 同面积；负极 5 mg/cm²、350 mAh/g；正极 10 mg/cm²、160 mAh/g | 1.75/1.60=1.09375 |
| 恒流容量 | 1 mA、3600 s | 1 mAh、3.6 C |
| 恒定电压能量 | 3 V、1 mA、3600 s | 0.003 Wh |
| iR 校正 | 0.50 V、+10 mA、Ru=5 Ω，未做补偿 | 0.45 V；负电流时遵循同一符号约定 |
| 库仑效率 | 充电 1.00 mAh，放电 0.98 mAh | 98% |
| 质量固含量 | 干固体 1 g，最终浆料固含量 40 wt% | 总浆料 2.5 g；最终溶剂总量 1.5 g，再扣除溶液带入量 |
| 非法参数 | 零面积、零分母、负绝对温度、质量分数不合计为 100% | 明确提示，不返回 NaN/Infinity 或自动猜值 |
| 时间轴异常 | 重复时间、时间倒退、每圈时间重置 | 明确分段或拒绝积分，不能默默排序改变实验顺序 |
| 多口径结果 | 单电极、双极活性物质、整电芯质量 | 结果标签必须区分，不能横向直接对比 |

对高级工具，先用已知参数的合成曲线验证回收能力，再用有完整实验条件的公开或授权样本交叉核对。至少覆盖不同扫描速率、噪声、基线漂移、充放电方向、相位符号和不适用的模型。
